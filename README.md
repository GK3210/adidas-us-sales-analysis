# adidas-us-sales-analysis
End-to-end analysis of $900M in Adidas US sales (2020-2021): cleaned 9,648 rows, ran EDA and built Excel and HTML dashboards with filters. The West leads sales but has the lowest margin (33.2%). Flagged a 10x Total Sales inconsistency affecting 96% of sales dollars and documented its impact. Tools: Python, Excel, HTML/JS.
